# Vertech download page

A responsive single-file landing page with a blue liquid-glass style. The download button points to the supplied MEGA link, and the footer includes Vertech's TikTok and YouTube links.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `vertech-download`).
2. Upload `index.html` directly to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site; the URL will appear in Settings → Pages.

The page credits the original creator of the modified APK and notes that it is unofficial. Modified APKs can carry security, privacy, or account risks.
